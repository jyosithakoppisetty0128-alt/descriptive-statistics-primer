Descriptive Statistics Primer – Task 9

Project Overview

This project focuses on understanding descriptive statistics using Python. A sample student marks dataset is used to calculate statistical measures and summarize the data.

Objectives

- Calculate mean, median, and mode.
- Understand variance and standard deviation.
- Identify minimum, maximum, and range.
- Calculate quartiles and percentiles.
- Generate a statistical summary.
- Interpret the results.

Dataset

A sample dataset containing student marks for 10 students was used for the analysis.

Tools & Technologies

- Python
- Pandas
- NumPy
- Google Colab

Statistical Analysis Performed

- Mean
- Median
- Mode
- Variance
- Standard Deviation
- Minimum and Maximum
- Range
- Quartiles
- Percentiles
- Descriptive Summary

Project Outcome

The statistical calculations were performed using Python, and the results were organized into a summary table. An Excel workbook was created containing the student dataset and statistical summary.

Conclusion

This project demonstrates how descriptive statistics help summarize and understand numerical data. It provides a basic understanding of data distribution, central tendency, and variability using Python.
